# ============================================================================
# Version Management
# ============================================================================

# mise is NOT installed from Homebrew, which is why it is not listed here.
#
# Homebrew publishes no bottle for mise on macOS 14 arm64 — this is a Tier 3
# configuration, so brew would build it from source, and with it z3, ninja,
# llvm, libssh2, llhttp, libgit2 and rust. That is an hours-long build that
# also wants newer Command Line Tools than are installed.
#
# install.sh uses mise's own installer instead, which fetches a prebuilt
# binary, verifies it against a checksum the installer carries, and puts it in
# ~/.local/bin. shell/zshrc already has that on PATH. mise then updates itself
# with `mise self-update`, so nothing here needs to track its version.
#
# What mise manages: Node and Bun, per mise/config.toml. It replaced nvm and
# pyenv, and still reads .nvmrc and .python-version in projects that have
# them. Rust stays with rustup and Python stays with conda.

# Build toolchain
# ============================================================================
# Homebrew keeps these because it needs them to BUILD other formulas from
# source, and on this platform it has to: macOS 14 arm64 is a Tier 3
# configuration with no bottles, so graphite2, jpeg-turbo, json-c, lz4,
# poetry, webp and zstd are all built locally. `brew uninstall` refuses to
# remove them for that reason, and `brew autoremove` leaves them alone.
#
# They are tracked so doctor.sh does not report them as untracked for ever.
# Once a macOS upgrade puts this machine back on a tier with bottles, nothing
# needs to build locally and `brew autoremove` should take them.
cmake
autoconf
pkgconf
python@3.15
